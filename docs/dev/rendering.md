# Rendering (ticket 09 — extend, don't rewrite)

Implementation notes, moved from the root `CLAUDE.md` on 2026-10-18 (read on demand; the
index is [README.md](README.md)). Extend them with the code they describe.

- **Files:** `crates/renderer/` is real now (`lib.rs` API + `RENDERER_VERSION` / `MIN_RENDERER_VERSION`, `html.rs` the event → HTML writer, `sanitize.rs` the raw-HTML/MathML allow-list sanitizer, `autolink.rs` GFM extended autolinks, `assets.rs` `Asset`/`Manifest`/`Target`, `escape.rs`, `refs.rs` = `MARKDOWN_OPTIONS` / `classify` / `normalize` — **moved here** from `assets/scan.rs`, which re-exports them, so scanner and renderer are one definition); it needs `std` (fine on `wasm32-unknown-unknown`; `make wasm-check` = `crates/renderer/tests/wasm.rs`, ignored under plain `cargo test`, checks renderer + sidecar for that target and is part of `make check`). Server: `server/render.rs` (route table in its header); store: `crates/store/src/render.rs`; CLI: `cli/rerender.rs`; corpus `fixtures/render/*.md` (+ `*.manifest.json`) with `insta` snapshots in `crates/renderer/tests/snapshots/` (`cargo run -p annotary-renderer --example render -- FILE.md [manifest.json]` prints a render; `cargo insta accept` / `INSTA_UPDATE=always cargo test -p annotary-renderer` after a deliberate output change — and bump `RENDERER_VERSION`).
- **API:** `annotary_renderer::render(md, &Options { assets, embeds }) -> Rendered { html, title }`; `render_html(md, assets)` = Documents (embeds on); `embeds: false` = Comment bodies (ticket 10: images/media/files become plain links); `Asset::from_manifest(&manifest_json)` reduces a commit's / Version's manifest to what the renderer uses — CLI and server both go through it, so `push`'s render == the server's fallback render (asserted over the corpus in `tests/render_api.rs`); `title(md)` = front matter `title:` else first H1 (display-only, ticket 10's list). `is_current(renderer)` = recorded version ≥ `MIN_RENDERER_VERSION` (bump MIN when a fix must apply retroactively on read; a newer client's render is never downgraded).
- **HTML contract (viewer-agnostic — every viewer builds on this, `docs/adr/0001`):** a fragment, no CSS/JS/chrome. Every block the renderer opens carries `data-l="A-B"` (1-based, inclusive source lines of its content: `p h1-h6 ul ol li blockquote pre table thead tbody tr th td hr section dl dt dd`, block `<math>`); soft breaks stay `\n` inside blocks; raw HTML written in the source keeps its own tags without `data-l`. Headings get GitHub-style slug `id`s (`goals`, `goals-1`), footnotes `id="fn-N"` / `fnref-N[-k]` inside `<section class="footnotes">` — **the viewer must namespace its own ids/classes** (`cd-…`) and may only rely on: `class="mermaid"` (`<pre>` for Mermaid JS), `class="language-x"` (no baked highlighting), `class="footnotes|footnote-ref|footnote-backref"`, `class="asset-missing" data-ref="REF"` (the missing-Asset placeholder — a `<span>` for embedded media, an `<a>` without `href` for links), `<math xmlns display="inline|block">` (latex2mathml, unsupported LaTeX shows `[PARSE ERROR: …]` / `<merror>` inline), task items `<input type="checkbox" [checked] disabled>`, table cells `align="left|center|right"`. Asset references: `<img src="/a/{hash}[?derivative=1]" alt title width height>` (dimensions/derivative from the manifest; SVG via `<img>`), image syntax on video/audio/PDF → `<video controls preload="metadata" src="/a/{hash}" width height>` / `<audio controls …>` / `<object type="application/pdf" data="/a/{hash}">` each with an `<a href>` fallback inside; text/Markdown Assets and every `[link](asset)` → plain `<a href="/a/{hash}">` (the viewer opens those in a new tab); unsupported/absolute/external references left as written; `javascript:`/`vbscript:`/`data:`(non-media) URLs dropped; raw HTML loses `<script>/<style>/<iframe>/forms`, `on*`, `style`, `class`, `data-*`, `srcset` (allow-lists in `sanitize.rs`). Front matter is never rendered. Output is byte-stable per (Markdown, manifest, `RENDERER_VERSION`).
- **Flow:** `push` renders after the Asset scan (`html = render_html(text, Asset::from_manifest(&manifest))`), sends `html_hash` in `blobs/check`, uploads the blob when lacking, commits with `html_hash` + `renderer: RENDERER_VERSION`; the server validates (`Store::check_render_fields`: hash shape → 400, blob present → 409 `blob_missing`, `renderer` a short printable token → 400) and stores both as sent (either alone is allowed — served through the fallback). `GET /api/v1/docs/{id}/versions/{n}` reports `renderer` / `html_hash` (nullable); `GET …/versions/{n}/html` (`read`; an API route under 06's rules — bearer or `cd_session` cookie via `Auth`, never auto-signed-in; the browser page never fetches it, ticket 10 composes `/d/{id}` in the `web_pages` router from `ensure_html`) serves the HTML (`text/html`, `ETag "{hash}"`, `Cache-Control: private, no-cache`, `X-Annotary-Renderer`) — `server/render.rs::ensure_html(st, member_id, &version)` renders with the same crate when the Version has no HTML or `!is_current(renderer)`, stores the blob and records it (`Store::set_version_html` → `version.rendered {version, renderer, html_hash, previous}` event, no activity bump); **ticket 10 composes `/d/{id}` from `ensure_html`.** `POST …/docs/{id}/rerender` (`write`) / `POST /api/v1/rerender` (owner, deleted Documents included) re-render every Version in place → `{id, name, vault, versions, changed, renderer}` / `{documents, versions, changed, renderer, docs[]}`. `version_blob_refs` already lists `html_hash`, so GC/purge treat the HTML like any Version blob (a rerender leaves the old blob to GC).
- **CLI:** `rerender DOC | --all` (`cli/rerender.rs`): rows `name id versions changed` (TTY header `NAME ID VERSIONS CHANGED`), summary `rerender: N Versions, K changed (renderer X)` on stderr, `--json` `{name,id,versions,changed}` (+ `vault`, `renderer`; single object for DOC, array for `--all`); exits 1 (neither/both), 2, 4 (`write` / owner-only). e2e group `47-render/` (`rerender.trycmd` pushes its own `rr-plan` with a unique SVG; `rerender-tty.toml` reads `ro-plan`).
