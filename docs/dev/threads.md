# Threads & Comments (ticket 04 — extend, don't rewrite)

Implementation notes, moved from the root `CLAUDE.md` on 2026-10-18 (read on demand; the
index is [README.md](README.md)). Extend them with the code they describe.

- **Files:** `crates/store/src/threads.rs` (Store API + `mention_candidates`, `parse_thread_id`/`parse_comment_id`, `BODY_CAP`), `crates/sidecar/src/range.rs` (`Range` `"L:C-L:C"` parse/format, `lines`, `extract` — 1-based lines, 0-based code-point cols, half-open, CRLF tolerated; shared by CLI/server/07's diff crate), `server/threads.rs` (route table in its header; `thread_json`/`comment_json`), `cli/thread.rs` (verbs + the row formatting `show`/`mentions` reuse: `text_row`, `print_rows`, `anchor_cell`, `list_record`, `footer`), `cli/mentions.rs`. Migration v3 (`threads`, `comments`, `thread_events`) is delimited `---- ticket 04 ----` in `migrations.rs`.
- **Store** (`Store::*`): `new_thread(by, doc, NewThread{subject, range, body, expect_version})` (span quote frozen from the head blob; `NotHead` when `expect_version` ≠ head; `RangeNotOnHead` for out-of-bounds/empty spans), `reply(by, doc, num, body, resolve) -> (ThreadView, CommentView)`, `set_thread_resolved(by, doc, num, bool) -> (thread, changed)` (idempotent), `edit_comment(by, is_owner, doc, "t7"|"t7.1", body)`, `delete_comment(...) -> (comment, changed)` (tombstone: body + mentions cleared, `deleted {at, by}` kept), `thread(doc, num)`, `threads(doc, &ThreadFilter{status, mentions, since, sort, include_hidden})` (default open, not fully tombstoned, document order = Document-level first, then span by current position, orphaned last — `ThreadView::document_order_key`), `thread_counts(doc, member) -> (open, mentions_me)`, `thread_counts_all(member)` (one pass for `list`), `mentions_for(member, vault_ids, since)`. Anchors are stored as `annotary_sidecar::Anchor` JSON (`original`/`current`/sparse `history`) — ticket 07 rewrites `current` + appends `history` on push (`threads.anchor` column, `crate::anchors::apply_on_push`) and added asset Threads (`subject = 'asset'`, `NewThread::asset(ref, line, body)`, `Anchor::new_asset`); the time-slice (`Store::threads_at`) reads `thread_events` (append-only resolve/reopen log). Every mutation is stamped with the head Version at that moment, bumps `last_activity_at` and appends `thread.created|replied|resolved|reopened` / `comment.edited|deleted` (`{thread, comment?, version, mentions?: [member ids]}`) — ticket 08's `wait` maps `mention` onto the `mentions` of `thread.created`/`thread.replied`. Mentions: `mention_candidates(body)` (kebab-case `@handle`, not in code spans/fences, word boundaries) → Member ids at post time; unknown handles stay text. `BODY_CAP` = 100k chars per Document (`StoreError::BodyCap{cap,current,adding}` → 409 `body_cap` → exit 5).
- **API:** `GET/POST /api/v1/docs/{id}/threads`, `GET/PUT/DELETE …/threads/{tid}` (PUT/DELETE take a Comment id), `POST …/threads/{tid}/replies|resolve|reopen`, `GET /api/v1/mentions?since=&vault=`; `doc_json_for(st, member, doc)` fills `open_threads`/`mentions_me` (use it, not bare `doc_json`, for anything a caller reads); `list` fills them in one pass and honors `mentions_me=1`. Server errors: 404 `no Thread t99 in NAME (ID)`, 409 `not_head` / `range_not_on_head` / `body_cap` / `deleted`, 403 `only the author (@h) or an owner may edit|delete tX`.
- **CLI:** every thread verb takes `DOC ID` (composite `plan/t7` = usage error, `reject_composite`); `-m -` reads stdin (trailing newlines dropped, `read_message`); `thread new` verifies the range on head client-side (`sidecar::range::extract`) and sends `version: head`; text output non-TTY omits the empty REPLIES field (prototype shape) — `--json` for parsing; anchor column `vN:L "exact"` / `vN:L refined|orphaned "exact"` — always from `anchor.current` (for orphaned = the last valid placement stamped with its Version); asset `asset REF`), `thread show` prints the full range; `show` = header + `thread list` rows, JSON `threads`; TTY footer `N resolved hidden — …` on stderr. Sidecar `threads[]` = every Thread by id (resolved and fully-tombstoned included — lossless), built by `server/sidecar.rs::thread_entry`.
