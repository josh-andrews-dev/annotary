Never compare a relative age (`0s`) between two calls; normalize it (CMD-25, `cli_docs.rs::without_age`).
- **A real spawned `serve`** (CMD-28): wrap the `Child` in `common::serve::ServeGuard` (`tests/common/serve.rs`; the test file says `mod common;`) right after `spawn()`. Its drop sends SIGTERM, waits `GRACE` (2 s), then SIGKILLs and reaps, so a panicking test leaves nothing running. Stop it on purpose through the guard: `sigterm()` + `wait_timeout(max)`, `kill()` (SIGKILL), `stop_with_output(max)` for a piped log, `take_stderr()` to read while it runs. `tests/serve_guard.rs` pins the behavior. Not covered: a test binary that is itself SIGKILLed (a canceled or timed-out run), where no drop runs.
