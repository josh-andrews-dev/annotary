| `crates/sidecar` | `annotary-sidecar` | the `.annotary` format, shared by CLI/server/WASM (`no_std`+`alloc`; deps declared directly, not via the workspace table): `model.rs` typed shape in the decided key order (derive `Serialize` in field order + `skip_serializing_if` = the omit-when-empty rules), `emit.rs` the one deterministic leaf-inline writer (any `Serialize` → ordered `Node` tree → layout; adding a section = adding a struct), `parse.rs` strict reader (`ParseError`: YAML / JSONL / minified / format), `binding.rs` `Binding` = what push reads (`id`, `vault`, `base_version` + hash, `actions_available`, `local_identity`/`matches_base`), `identity.rs` (`DOC_ID_ALPHABET`, `is_document_id`, `sha256_hex`, `version_hash`), `range.rs` source coordinates, `anchor.rs` (ticket 07: `Anchor::new_span/new_asset/record/placement_at/at` — the sparse-history rule) |
| `crates/renderer` | `annotary-renderer` | Markdown → viewer-agnostic HTML (ticket 09; see "Rendering" below): `html.rs` writer, `sanitize.rs`, `autolink.rs`, `assets.rs`, `refs.rs` (`MARKDOWN_OPTIONS`/`classify`/`normalize`, re-exported by `assets/scan.rs`); std, builds for wasm32 (`make wasm-check`) |
| `crates/diff` | `annotary-diff` | re-anchoring (ticket 07; see "Re-anchoring" below): `lib.rs` `Mapping`/`reanchor`/`Span`/`Placement`/`Status`/`asset_status`, `mapping.rs` histogram line diff (`imara-diff`) + Myers word-token diff inside changed lines (`similar`, UAX #29 tokens) → equal segments, `text.rs` flat coordinates, `html.rs` the rendered inline diff of two Versions (Compare Versions, `rendered_diff`); std, builds for wasm32 (`make wasm-check`); `tests/fixtures.rs` replays `fixtures/anchoring/`, `tests/prototype_oracle.rs` the sidecar prototype's sparse-history golden |
