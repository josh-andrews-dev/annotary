# Re-anchoring across Versions (ticket 07 — extend, don't rewrite)

Implementation notes, moved from the root `CLAUDE.md` on 2026-10-18 (read on demand; the
index is [README.md](README.md)). Extend them with the code they describe.

- **Files:** `crates/diff/` (the pure function; see the workspace map), `crates/sidecar/src/anchor.rs` (`Anchor::new_span(version, range, exact)` / `new_asset(version, hash, ref, line)`, `record(n, status, range, line, exact) -> changed` (sparse: a history entry only when `(range|line, status)` changed; `current` rewritten; orphaned sticky — once orphaned nothing changes; on the first orphaning `current` freezes the last valid range/line stamped `n-1`), `placement_at(n)` (last entry ≤ n, stamped n; orphaned ⇒ last valid range stamped with the last valid Version), `at(n)` (the whole Anchor as of n); constants `ANCHORED/REFINED/ORPHANED`), `crates/store/src/anchors.rs` (see below), `server/threads.rs` (`?version=&anchor=`, `subject: asset`), `server/docs.rs` (`placements_from`, `asset_lines`, `reanchored` in the push response), `cli/push.rs::reanchor_for`, `cli/thread.rs`, `assets/scan.rs::reference_lines(md) -> Vec<(ref, line)>` (first root-level mention of each normalized ref — the display-only "referencing line" of an Asset Thread; the server handler computes it for `POST threads` (asset) and for `PushInput.asset_lines`).
- **The algorithm** (`annotary_diff::Mapping::new(text_n, text_n1)` once per push, `.place(&Span{range, original, orphaned}) -> Placement{status, range?, exact?}`; `reanchor()` for a batch; `asset_status(already_orphaned, present)`): histogram line diff (`imara-diff`), then inside every changed hunk a Myers diff (`similar`) of **UAX #29 word tokens** (words, spaces, punctuation, one per CJK ideograph, line breaks) — tokens rather than raw characters because a character LCS of unrelated text is never empty and would turn type-overs/rewrites into "refined" on garbage. The new span = first surviving char … last surviving char of the old span (sticky inside: insertions/replacements between survivors are covered; non-sticky at the edges: boundary insertions and edge replacements fall outside; deletions shrink). Nothing survives — or no *word* of the quote (a letter when the quote has letters, a digit when only digits, any non-blank char otherwise) — ⇒ orphaned; text == `original.exact` ⇒ anchored; else refined with `exact`. The refined range never gains leading/trailing whitespace the quote lacks. Zero-width spans and already-orphaned spans ⇒ orphaned; a range not on text N ⇒ `Err(RangeError)` (a corrupt anchor, never a guess). Hunks over `mapping::MAX_HUNK_TOKENS` (20k) fall back to imara-diff's bounded heuristic Myers on the same tokens. Everything is a pure function of the two texts — no time limits, no randomness; change it only with the fixture table (`fixtures/anchoring/`, `make.py`) and the prototype oracle in agreement.
- **Wire shape / store** (`crates/store/src/anchors.rs`): commit `placements: [{thread, status, range?, line?, exact?}]` (`SubmittedPlacement`; `parse_placements` shape-checks: thread id, one of three statuses, parseable range, no duplicates) + `placements_from: N` (the head the pusher mapped from). `compute_placements(&[(id, Option<Anchor>)], text_n, text_n1, &manifest_n1, &asset_lines) -> Vec<SubmittedPlacement>` is what CLI and server both run (Document-level Threads skipped; asset Threads: hash present in the new manifest ⇒ anchored with the line of the original `ref` (else the first ref with that hash), gone ⇒ orphaned); `summarize(threads, placements) -> Reanchored{total, anchored, refined, orphaned, changed, verified, computed}` (Document-level count as anchored) and `Reanchored::line()` = `threads: N re-anchored — a anchored, r refined, o orphaned (+1 refined: t3; +2 orphaned: t4, t8 | unchanged)`. `apply_on_push` runs inside `push_version`'s tx right after `insert_version` (a moved head with `already` never re-anchors): loads every Thread (resolved and tombstoned too — `orphaned ⊥ resolved`), drops the submission when `placements_from ≠ head`, runs `check_submission` on every kept entry (status fits the kind and stickiness, range on the new text, anchored ⇒ text == quote, refined ⇒ `exact` == text there), and with `Store::verify_edge()` (default on; `serve --verify-edge on|off` → `set_verify_edge` — ticket 17 renamed it from `--verify-placements`, kept as an alias, because it also gates the containment recheck) recomputes and refuses any mismatch (`StoreError::InvalidPlacements` → 400 `invalid_placements` → exit 1 — a wrong placement would be a corrupted Anchor forever); Threads without a submission are placed by the server (`computed`), then `Anchor::record` + `UPDATE threads SET anchor`. Asset Threads: `NewThread::asset(ref, line, body)` → `Store::new_thread` reads the head manifest (`AssetNotOnHead{reference, head, available}` → 409 `asset_not_on_head`, `AssetMissing` → 409 `asset_missing`, both exit 5). `ThreadFilter.anchor_status: Option<Vec<String>>` filters by placement status (a Document-level Thread counts as `anchored`); `ThreadView::placement_status()`. **Time-slice:** `Store::threads_at(doc, n, &filter)` rebuilds every Thread as of Version n — created ≤ n, Replies ≤ n, resolved per the last `thread_events` row with `version ≤ n`, `anchor = anchor.at(n)` (+ `current.exact` extracted from Version n's text when refined), `updated_at` recomputed; edits/tombstones are not versioned; `VersionNotFound` for an unknown n.
- **API:** `GET …/threads?version=N` (404 unknown N; response `version` = N, `head` = the head) and `&anchor=anchored,refined,orphaned` (400 on other words); `POST …/threads {subject: "asset", ref}` (the handler normalizes the ref and computes the line); push response `reanchored` (the `Reanchored` JSON, null when `already`) and the server logs one line per re-anchored push.
- **CLI:** `push` (`reanchor_for`, before `blobs/check`; skipped for a new Document, an unreadable target or content identical to head): `GET docs/{id}` (head, hash, md_hash) → `GET …/threads?status=all&hidden=1` (sorted by id) → head blob → `compute_placements` → prints `Reanchored::line()` on stderr right after the `assets:` line, sends `placements` + `placements_from`; `--json` `threads {re_anchored, anchored, refined, orphaned, changed{tN: status}}` (in `all`, not `default`). Mapping is incremental *because it starts from the head's stored placements* (they already carry every earlier Version) — never map base→new. `thread list --status S` (comma list → `&anchor=`; unknown word = exit 1) and `--version N` (`&version=`; TTY note `Threads as they were on vN (head is vH) — read-only` when N ≠ head; unknown N = exit 2); the TTY footer (`thread::footer(ctx, body, filtered_open, all_flag, status_filtered)`) adds `N orphaned — thread show prints their last placement; --status anchored,refined hides them` unless `--status` is on (`show DOC` prints it too). `thread new DOC --asset REF -m MSG` (conflicts with ANCHOR/`--document`; the CLI normalizes REF with `assets::scan::normalize`) prints `tN <tab> asset REF`. `anchor_cell`/`anchor_json` read `anchor.current` for every status (`vN:L orphaned "quote"` = the last valid placement; `--json` `anchor {version, range, status, exact, now?}` — `now` = `current.exact` when refined); `thread show` prints `  now: "…"` after the body of a refined span.
- **Sidecar:** nothing new to write — `threads[].anchor` is the stored `Anchor` (`current.exact` present only when refined; orphaned `current` = last valid placement; history sparse) and `pull` writes it as is (`50-threads/pull-reanchor.out/`).
- **Decisions to keep:** word-token diff (not raw chars) — documented deviation from the spec's letter, required by D8/D10'/G10 and the ticket's "rewritten paragraph ⇒ orphaned"; survivor rule as strict as the quote allows (letters > digits > any non-blank); refined ranges trimmed of edge whitespace the quote lacks; server verifies *all* submitted placements when on (Phase 2 may sample or trust); a submission from a stale head is ignored, never refused; identical content (`already`) skips re-anchoring entirely (the sparse rule answers for the missing number).
